# 오프라인 GPS 계기판

KTX·비행기 안에서 인터넷 없이 GPS만으로 **속도 / 진행 방향 / 고도 / 위치 / 이동거리**를 보여주는 웹앱(PWA)입니다.

## 기능
- 현재 속도(km/h, 노트, m/s), 최고·평균 속도
- 진행 방향 나침반(위쪽 = 진행 방향), 16방위 표시
- 고도(비행기 모드는 ft + m), 위도·경도, GPS 정확도
- 진행 방향 가장 가까운 KTX역 / 공항 + 도착 예상 시간
- 목적지 선택 시 남은 직선거리와 도착 예상 시각
- 최근 15분 속도 그래프, 지도 없는 이동 궤적(역·공항 점 표시)
- **GPS 끊김 구간 추정**: 확장 칼만필터 + IMU(가속도·자이로). GPS가 잡히는 동안 폰 자세와 센서 치우침을 자동 학습하고, 터널 등에서 끊기면 속도·방향·위치를 이어서 추정(± 오차 표시)
- 데모 주행: GPS 없이 가상 주행(중간 터널 포함)으로 기능 확인
- 화면 켜두기(Wake Lock), GPX 저장(실측점만), 기록 자동 보관

## 폰만으로 설치하기 (GitHub Pages, PC 불필요 · 약 10분)
위치 기능은 **https 주소에서만** 동작합니다. GitHub Pages는 무료로 https를 줍니다.

1. 폰에서 `gps-dash.zip`을 풀기 (아이폰: 파일 앱에서 zip 탭 / 안드로이드: 내 파일 앱 → 압축 풀기)
2. 폰 브라우저로 github.com 로그인(계정 없으면 가입) → 오른쪽 위 `+` → **New repository**
   - 이름 `gps-dash`, **Public** 선택 → Create repository
3. 새 저장소 화면에서 **uploading an existing file** 링크 탭 (또는 Add file → Upload files)
   - `choose your files`로 압축 푼 파일 7개 모두 선택 → **Commit changes**
4. 저장소 **Settings → Pages** → Source: *Deploy from a branch*, Branch: **main / (root)** → Save
5. 1~3분 뒤 `https://아이디.github.io/gps-dash/` 접속 → 위치·동작 센서 권한 허용
6. 홈 화면에 추가 (아이폰: 공유 → 홈 화면에 추가 / 안드로이드: ⋮ → 앱 설치)

> 데스크톱 화면이 필요하면 브라우저 메뉴의 "데스크톱 사이트 요청"을 켜세요.
> PC가 있다면 app.netlify.com/drop 에 폴더를 끌어다 놓는 방법이 가장 빠릅니다.

## 폰에서 테스트하는 순서
1. **정지 상태 확인**: 시작 → 위치 권한 허용 → 상태가 초록색, 정확도 ±수 m인지 확인. 아래 진단 줄에서 GPS 간격(보통 1초), IMU Hz(보통 50~100Hz) 확인
2. **비행기 모드 확인**: 비행기 모드 켜고 앱을 닫았다 다시 열기 → 앱이 열리고 GPS가 잡히면 오프라인 OK
3. **IMU 보정**: 폰을 차·버스·지하철·KTX 안에 고정(거치대/테이블)하고 출발·정지·커브를 몇 번 겪으면 IMU 막대 4칸 + "보정 완료"
4. **관성 추정 검증**: 이동 중 "GPS 30초 차단" → 차단 중 실시간 오차, 끝나면 최종 오차가 목록에 쌓임. IMU 보정 전/후로 비교해 보세요
5. **진짜 터널**: KTX 터널 통과 후 "GPS 복귀 · 끊긴 동안 추정 위치 오차" 메시지 확인
6. 이상하면 **센서 로그 CSV 저장** → 파일을 보내주시면 분석·튜닝해 드려요

## 탑승 전 체크
1. 인터넷 되는 곳에서 홈 화면 아이콘으로 **한 번 열어** 캐시 저장
2. "시작"을 눌러 위치 권한 허용(정확한 위치 ON) — 한 번 잡아 두면 오프라인 첫 측위가 빨라짐
3. 비행기 모드여도 GPS는 켜져 있음. 창가에 폰을 두면 수신이 훨씬 좋음

## 알아둘 점
- 화면이 꺼지면 브라우저가 GPS를 멈춥니다 → "화면 켜두기" 사용
- 터널, 창 없는 좌석, 기체 안쪽에서는 신호가 끊길 수 있음
- 역·공항 좌표는 근사값(수백 m 오차)
- 관성 추정은 시간이 지날수록 오차가 커집니다(시뮬레이션 기준 50초 터널에서 약 30m, 실제 폰은 센서 품질에 따라 더 클 수 있음). 오차가 3km를 넘거나 10분이 지나면 추정을 멈춥니다
- 폰을 들어 자세가 크게 바뀌면 IMU 보정을 다시 합니다. 테이블·거치대에 고정해 두는 게 가장 좋아요
- 백그라운드 기록까지 원하면 네이티브 앱(Flutter/React Native)으로 옮겨야 합니다
