# GPS·IMU 칼만 필터

폰의 GPS와 IMU(가속도계·자이로)를 확장 칼만필터(EKF)로 합쳐 **위치·속도·방향**을 추정하고, 그 과정을 시각화하는 웹앱입니다. 오프라인에서도 동작합니다(PWA).

**실행:** https://jh-escl.github.io/gps-dash/

## 필터
상태 `x = [동 E, 북 N, 속력 v, 방향 ψ, 자이로 치우침 b_g]`

| 단계 | 내용 |
|---|---|
| 예측 (IMU, 10 Hz) | `v += a·dt`, `ψ += (s·r − b_g)·dt`, `E += v·sinψ·dt`, `N += v·cosψ·dt` |
| 보정 (GPS, ~1 Hz) | 위치(+ 속력, 방향이 있으면), 이상치는 게이트(4σ)로 거름 |
| GPS 없음 | 예측만 계속, 불확실도(2σ)가 커짐 |

**IMU 정렬(폰 자세 무관):** 중력 방향으로 수평 가속 `h`와 수직축 회전 `r = ω·up`을 뽑고, GPS가 잡히는 동안
- 진행방향 가속 `a = f·[h, 1]` 을 재귀 최소제곱으로,
- 회전 부호 `s` 를 자이로–GPS 방향 변화 상관으로 학습합니다.
자이로 치우침 `b_g`는 필터 상태로 추정합니다.

## 화면
- **궤적**: GPS 측정점, 칼만 추정 경로, 2σ 불확실도 원. GPS가 없던 구간은 주황색입니다.
- **시계열**: 속도, 방향, 위치 오차(필터 예상 2σ vs 실제 GPS 차이), IMU 가속·회전 vs GPS 변화량.
- **GPS 차단**: 필터에 GPS를 넣지 않고 IMU만으로 추정하게 한 뒤, 실제 GPS(회색 점)와 비교합니다.
- **시뮬레이션**: 비스듬히 놓인 폰을 실은 가상 차량으로 센서 없이 확인할 수 있습니다.
- **필터 내부**: 공분산 노름 ‖P‖_F(SI), 무차원 칼만 게인 노름 ‖K̃‖_F(K̃ij = Kij·σ잔차j/σ상태i), 위치 잔차 ‖y‖와 그 추이 그래프.
- **초기화**: 필터, IMU 정렬, 기록을 지우고 다음 GPS부터 새로 시작합니다.
- **CSV**: GPS, 필터, IMU 기록을 저장합니다.

## 파일
```
index.html      화면
js/kalman.js    EKF
js/imu.js       IMU 전처리 + 자동 정렬
js/sim.js       시뮬레이터
js/viz.js       차트·궤적 그리기
js/app.js       센서 연결, 루프, 화면 갱신
sw.js           오프라인 캐시
```

## 사용 팁
- 폰을 거치대나 테이블에 고정하세요. 자세가 크게 바뀌면 IMU를 다시 정렬합니다.
- IMU 정렬에는 GPS가 잡힌 상태에서 몇 번의 가감속과 커브가 필요합니다. 정렬 전에는 속도·방향을 일정하다고 가정하고 추정합니다.
- 화면이 꺼지면 브라우저가 센서를 멈춥니다(실행 중에는 화면 켜짐 유지를 요청합니다).
